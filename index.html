Buen Camino! 🐚

葡萄牙海岸線朝聖之旅備忘錄

出發準備
Lisboa ➔ Porto 火車/公車
⚠️ 注意點
1-先買波多主教座堂i處購買朝聖護照。 2-在葡萄牙打招呼用語是 Bom Caminho，到西班牙時要改成 Buen Camino！兩者皆有打招呼和祝福一路順風/平安的意思。
Day 1
波多 ➔ Labruge 27 km
🚶‍♂️ 路線細節

Gronze：Costa Etapa 1 Porto → Foz do Douro福茲杜羅河 → Matosinhos → Leça da Palmeira → Aldeia Nova (Perafita) → Praia de Angeiras (Lavra) → Praia de Labruge海灘 → Labruge

⚠️ 注意點
從波多證交所處下切到杜羅河畔，沿河畔前行。出海口接著沿大西洋海岸沙灘邊道路走12公里。貝殼和黃箭頭標記密集明顯，在一高架橋處，轉彎處有黃箭頭指引，走上天橋穿越河岸後，繼續遵循黃箭頭左轉，約3.5公里後見大西洋沙灘。 注意：部分木棧道有塌陷或腐化空洞，請小心行走。經過小漁村後直抵庇護所。
Day 2
Labruge ➔ 波瓦迪瓦爾津 19 km
🚶‍♂️ 路線細節

Gronze：Costa Etapa 2 Labruge → Praia de Labruge → Vila Chã → Louçá-Mindelo → Vila do Conde → Caxinas(可不經) → Póvoa de Varzim

⚠️ 注意點
從前一天的大西洋海灘岸走就接上路徑。 注意：沙丘木棧步道部份被沙掩蓋及破損不堪，襪子鞋子容易進沙，需特別注意步伐。 穿過Ave河橋樑後抵達 Póvoa de Varzim。這裡有三間不同風格餐廳營業。黃箭頭和貝殼明顯。
Day 3
波瓦迪瓦爾津 ➔ Marinhas 26 km
🚶‍♂️ 路線細節

Gronze：Costa Etapa 3 Póvoa de Varzim → A Ver-o-Mar → Aguçadoura → Apúlia → Fão → Esposende → Marinhas

⚠️ 注意點
從沿海開始，然後稍微轉向內陸，朝向 Fão 及其橫跨 Cádavo 河的橋樑。 路況包含：長廊、木棧道、土路，最後五公里是鵝卵石和柏油人行道。標記明顯。
Day 4
Marinhas ➔ 維亞納城堡 24 km
🚶‍♂️ 路線細節

Etapa 4: Marinhas - Viana do Castelo Marinhas → Mar → Belinho → Antas → Castelo do Neiva → Chafé → Anha → Darque → Viana do Castelo

⚠️ 注意點
暫時離開海岸進入内陸，經過村鎮住宅，教堂右轉進入上下坡林蔭步道。 通往 Neiva 河床是由二塊大石板鋪成的小橋，此段約5公里。一連串下坡通過 Ponte Eiffel 橋後，下橋左轉直走抵達教堂旁。
Day 5
維亞納城堡 ➔ Caminha 23.65 km
🚶‍♂️ 路線細節

Etapa 5: Viana do Castelo - Caminha Viana do Castelo → Areosa → Carreço(建議往下走沿莫萊多海灘向前，較美，增1.1km) → Afife → Vila Praia de Âncora → Moledo → Caminha

⚠️ 注意點
官方箭頭不明顯。若沿海岸線走，部分路徑需繞回公路（車多危險）。如果想持續走海岸線，請依賴地圖找路，但可能會因此多走冤枉路（曾有紀錄走到30公里，需重新找路）。抵達 Vila Praia de Âncora 後可順利步行至 Caminha。
Day 6
Caminha ➔ 維拉·諾瓦·德·塞爾韋拉 15.2 km
🚶‍♂️ 路線細節

Etapa 6E 前半段 Caminha → Seixas → Lanhelas(利用人家樓梯穿過果園。陡峭土石路穿過樹林，繞道穿隧道跨越A-28公路) → Gouvim → Gondarém → Loivo → Vila Nova de Cerveira

⚠️ 注意點
推薦 D. Lima 餐廳 (Rúa 25 de Abril)，傳統且價格實惠，份量足 (週一休息)。Lanhelas 附近需爬樓梯穿果園及陡峭土石路，注意體力分配。
Day 7
維拉·諾瓦·德·塞爾韋拉 ➔ Tui 16.8 km
🚶‍♂️ 路線細節

Etapa 6E 後半段 Vila Nova de Cerveira → Lovelhe → Reboreda → Campos → Vila Meã → São Pedro da Torre → Cristelo Covo → Valença → Tui

⚠️ 注意點
今日將跨越國界進入西班牙 (Valença 跨橋至 Tui)，記得調整時差（西班牙比葡萄牙快一小時），打招呼改成 Buen Camino！
Day 8
Tui ➔ O Porriño 16.1 km
🚶‍♂️ 路線細節

Etapa 21 前半段 Tui → Ribadelouro → O Porriño

⚠️ 注意點
從 Ribadelouro 途經阿斯甘達拉斯 (As Gándaras) 自然保護區，沿著盧羅河 (Louro River) 行進，請保持河流在你的右側。
Day 9
O Porriño ➔ Redondela 15.8 km
🚶‍♂️ 路線細節

Etapa 21 後半段 O Porriño → Ameiro Longo → Veigadaña → Rúa (Mos) (有爬坡) → Capilla de Santiaguiño → Padrón (Saxamonde) → Redondela

⚠️ 注意點
經過 Mos 區域時會有爬坡路段，請預留體力。
Day 10
Redondela ➔ 蓬特韋德拉 21 km
🚶‍♂️ 路線細節

Etapa 22 Redondela → Cesantes → Soutoxuste → Arcade → Pontesampaio → Pontevedra

⚠️ 注意點
有兩次分別為 120米和 135米不平整漸進的爬坡，開始時微陡。 走過橫跨河道二岸的古羅馬橋，進入林蔭步道後直抵城鎮(位於古城1.5公里入口處)。此城為哥倫布聖瑪利亞號建造地，充滿歷史。
Day 11
Pontevedra 蓬特韋德拉 休息/觀光
🚶‍♂️ 路線細節

無車城一日遊

⚠️ 注意點
歷史古蹟推薦：Plaza de Peregrina/聖女教堂、Iglesia de San Francisco聖弗朗西斯科教堂、真正的聖母瑪利亞大教堂、德克羅廣場。好好享受這個無車城市的悠閒。
Day 12
Pontevedra ➔ A Armenteira 23 km
🚶‍♂️ 路線細節

Etapa 1E: Pontevedra - A Armenteira (Spiritual Variant 性靈之路) (D11-3-走E1天橋後的第2叉路往左) → O Freixo → Parada → Cabaleiro → Fragamoreira → Muíño → O Convento → A Seara → A Seca → Casalvito → Combarro → Xuviño → O Esperón → A Armenteira

⚠️ 注意點
今天轉進性靈之路路線！路徑是「公路-海岸-森林」串連循環。 途中經過 poio、Combarro 兩個村落。葡萄園會變多，海拔爬升至270公尺處有平台可俯瞰河岸景觀。 *本日路徑務必核對 Gronze Etapa 1E 資訊。*
Day 13
A Armenteira ➔ 比拉諾瓦德亞羅薩 23 km
🚶‍♂️ 路線細節

Etapa 2E: A Armenteira - Vilanova de Arousa A Armenteira → A Barcia → A Torre → Barrantes → Cabanelas → Ponte Arnelas → Gombra → Mouzos → A Igrexa → Cores → San Roque do Monte → O Terrón → Vilanova de Arousa

⚠️ 注意點
1- 狹窄山徑下切到河岸一座石頭屋旁走右岸，很像淡蘭古道。下切到平地後出現寬闊河，沿蜿蜒河岸走。走過橋抵達城鎮。 2- 天候警告：A Armenteira 若下雨溼滑，一定要改走自行車道，沿河走會很危險！
Day 14
比拉諾瓦德亞羅薩 ➔ Padrón 35 km (搭船)
🚶‍♂️ 路線細節

Etapa 3E: Vilanova de Arousa - Padrón Vilanova de Arousa (坐船) → Pontecesures → Padrón

⚠️ 注意點
坐船抵達 Pontecesures。28公里約1小時航程，船費30歐。 參考 Gronze：從維拉諾瓦德阿羅薩搭船前往蓬特塞蘇雷斯。
Day 15
Padrón ➔ 聖地牙哥 (Santiago) 24.4 km
🚶‍♂️ 路線細節

Etapa 25: Padrón - Santiago de Compostela Padrón → Iria Flavia → Pazos de Iria → A Escravitude → Cruces → Angueira de Suso → Areal → Picaraña → O Faramello → Rúa de Francos → Pedreira → Raíces → O Milladoiro → Santiago de Compostela

⚠️ 注意點
終點站！準備迎接大教堂廣場的感動。記得去領取星象圖證書 (Compostela)。
